# Contributing

Thanks for considering a contribution!

## How to contribute

1. Fork this repository
2. Create a feature branch: git checkout -b feat/my-feature
3. Commit your changes with a clear message
4. Push the branch and open a Pull Request to main

## Code style

- Keep commands self-contained under src/commands/
- Register new files via src/handlers/commands.js
- Reuse the Components V2 helpers in src/utils/v2.js

## Reporting issues

Use the issue templates (bug report / feature request) so reports stay consistent.
