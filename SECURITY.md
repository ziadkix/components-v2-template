# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| latest  | yes       |

## Reporting a vulnerability

Please do **not** open a public issue for security reports.

Report privately via [GitHub private vulnerability reporting](https://github.com/ziadkix/components-v2-template/security/advisories/new) or by contacting the maintainer directly.

## Scope notes

- This project is a bot template: never commit real tokens; keep them in .env (git-ignored).
- Review scripts/deploy.js before sharing it, since it authenticates with your bot token.
